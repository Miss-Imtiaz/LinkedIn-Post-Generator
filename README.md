# 👑 Hybrid LinkedIn Post Generator

A powerful, hybrid LinkedIn post generator built with Python and `ipywidgets`. This tool streamlines your "Building in Public" workflow by automating the creation of professional and conversational content for LinkedIn.

## ✨ Key Features
* **Dual Language Support**: Easily toggle between **English (Professional)** and **Roman Urdu (Conversational)** styles.
* **Smart Intent Classifier**: Automatically detects post intent (Project, Internship, Job, Learning, or Tips) based on your input.
* **Intelligent Text Processing**: Includes automatic capitalization for proper nouns and sentence-case correction to ensure polished content.
* **File & Media Support**: Attach multiple files, including images, with automatic previews and download links within the UI.
* **Custom Tag Management**: Dedupes tags, sorts them alphabetically, and ensures proper `#` formatting.
* **User-Friendly UI**: A clean, interactive Jupyter-based interface with dynamic input fields.

## 🛠 Tech Stack
* **Python**
* **ipywidgets** (for the interactive UI)
* **IPython Display** (for rendering HTML/Images)
* **Regular Expressions (re)** (for smart text cleaning)

## 🚀 How to Run
1. Ensure you have Jupyter Notebook or JupyterLab installed.
2. Clone this repository:
```bash
   git clone (https://github.com/Miss-Imtiaz/LinkedIn-Post-Generator/edit/main)```
3. Open linkedin_post_generator.ipynb in your environment.

4. Run all cells to initialize the UI widgets.

5. Fill in the details, attach your project assets, and click ⚡ **Generate Post**.
